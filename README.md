# متجر «ياسر أبو الشيخ» للإلكترونيات ⚡

متجر إلكتروني عربي متكامل (RTL) بتصميم داكن فاخر بلمسات ذهبية — واجهة عملاء + لوحة تحكم.

## المحتويات

| الملف | الوصف |
|---|---|
| `yasir-store-server-v1.zip` | السيرفر الكامل الجاهز للنشر (FastAPI + SQLite + الواجهة) |
| `yasir-store-website-v1.zip` | ملفات الواجهة الأمامية فقط (HTML/CSS/JS) |
| `README.md` | هذا الملف |

## التشغيل محلياً

```bash
unzip yasir-store-server-v1.zip && cd yasir-store-server
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
./venv/bin/python -m uvicorn server:app --host 0.0.0.0 --port 8000
```

ثم افتح: http://localhost:8000

- المتجر: http://localhost:8000
- لوحة التحكم: http://localhost:8000/admin.html
- بيانات الدخول الافتراضية: `admin` / `yasir123`

## النشر على Render (مجاني)

1. ارفع محتويات `yasir-store-server-v1.zip` إلى مستودع GitHub جديد.
2. في Render: New → Web Service → اختر المستودع.
3. سيكتشف Render ملف `render.yaml` تلقائياً (runtime: python).
4. غيّر متغيرات البيئة `ADMIN_USER` و `ADMIN_PASS` لبيانات دخول خاصة بك.
5. انشر — ستحصل على رابط مثل `https://yasir-store.onrender.com`.

> ملاحظة: على الخطة المجانية قد تُمسح قاعدة البيانات عند إعادة النشر (ملفات مؤقتة).
> للإنتاج الحقيقي أضف قرصاً دائماً (Disk) من إعدادات الخدمة.

## المزايا

**واجهة العملاء:**
- صفحة رئيسية (عروض + أقسام + منتجات مميزة)
- شبكة منتجات مع بحث وفلترة حسب القسم وفرز (السعر/الأحدث/التقييم)
- صفحة تفاصيل منتج (صور، مواصفات، تقييمات العملاء + إضافة تقييم)
- سلة مشتريات + إتمام طلب (الدفع عند الاستلام — مناسب لسوريا)
- تتبع الطلب برقم الطلب (مثال: YS-AB12CD)

**لوحة التحكم:**
- تسجيل دخول آمن (جلسات برموز مؤقتة)
- إضافة/تعديل/حذف منتجات مع رفع صور
- عرض الطلبات وتغيير حالتها (جديد → قيد التجهيز → تم الشحن → تم التوصيل)
- إحصائيات: الإيرادات، الطلبات، المنتجات، تنبيه المخزون المنخفض

## البيانات التجريبية

12 منتجاً في 6 أقسام (هواتف، لابتوبات، صوتيات، ساعات ذكية، إكسسوارات، أجهزة منزلية ذكية)
+ صور مولّدة بالذكاء الاصطناعي + تقييمات تجريبية. الأسعار بالليرة السورية.

## التقنية

- Backend: FastAPI + SQLite (بدون مكتبات خارجية ثقيلة)
- Frontend: HTML/CSS/JS خام — عربي RTL بالكامل
- الصور المرفوعة تُحفظ في `data/uploads`
